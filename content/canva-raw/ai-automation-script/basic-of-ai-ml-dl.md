## Slide 3

AI (Artificial Intelligence) is a broad concept where machines are designed to think and
make decisions like humans. The goal of AI is to perform tasks that normally require
human intelligence — such as reasoning, problem-solving, or understanding language.

WHAT IS MACHINE LEARNING (ML)?

Machine Learning is a subset of AI. Instead of programming rules, we train the system
with data, and it learns patterns from that data to make decisions.

An ML model can learn from past cyberattacks to detect
future threats by recognizing patterns.

## Slide 6

Deep Learning is a more advanced type of machine learning. It’s inspired by how the
human brain works, using neural networks that are layered deeply (hence "deep").

WHAT IS DEEP LEARNING?

Deep Learning can help identify malware just by looking at how a
program behaves, without needing to scan its code line-by-line.

EXAMPLE

What is Deep Learning?

Example
