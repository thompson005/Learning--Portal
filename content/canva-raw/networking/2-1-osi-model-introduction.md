In the 1970s and early 1980s, the networking world was a bit of a mess. Companies like IBM developed their own systems and protocols, meaning that their machines would only communicate with other IBM machines. This practice, called vendor lock-in, made it difficult for different brands to interact with one another.

for example, IBM had its proprietary networking protocol suite called System Network Architecture (SNA), which was designed to work only with IBM hardware.

THE BIRTH OF THE OSI MODEL

To address this problem, the International Organization for Standardization (ISO)
developed the OSI (Open Systems Interconnection) model in the early 1980s. The goal
was to create a standard framework that would allow various network technologies
to communicate with each other, regardless of their manufacturer. The OSI model
broke down the complexities of network communication into 7 distinct layers, each
with specific functions.

This was revolutionary because it gave developers a clear and structured approach
to design networking protocols that were interoperable. It allowed different systems
(IBM, Cisco, etc.) to communicate by following the same rules for each layer.

model is a conceptual framework that standardizes the
functions of a networking system. The OSI model is divided
into seven layers, each of which has a specific role in data

reliable data transmission between devices across networks.

The OSI model helps us understand how data travels
from one computer to another, just like how a
message gets delivered through a postal system.
