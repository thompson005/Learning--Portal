IPv4

 A 32-bit address represented as four decimal
numbers separated by dots. IPv4 provides
approximately 4.3 billion unique addresses. 

 (e.g., 192.168.1.1)

IPv6

A 128-bit address designed to replace IPv4 due to
address exhaustion. IPv6 uses hexadecimal format
and can support a vastly larger number of addresses.

Private IP addresses are reserved for use

home or office. Devices on the same local
network use private IP addresses to
communicate with each other, while the
router translates these to a public IP for
internet communication using Network
Address Translation (NAT). Used for internal
communication within a local network.
