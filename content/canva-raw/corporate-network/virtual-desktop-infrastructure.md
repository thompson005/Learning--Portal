WHAT IS VIRTUAL DESKTOP
INFRASTRUCTURE?

Virtual desktop infrastructure (or VDI) is a technology
that allows users to access desktop environments
hosted on a centralized server instead on local machines.

Users connect to virtual desktop via remote
connections, enabling them to work from any device
with just internet access.

This setup enhances flexibility and mobility in the
workplace while maintaining security.

KEY COMPONENTS OF VDI &
HOW IT WORKS?

Centralized Servers:
Desktops are hosted on

Hypervisor:

that creates and manages
virtual machines (VMs) on
which the desktops run.

Connection Broker:
Manages user
connections and
allocates resources
from the server to the
end-user device.

KEY COMPONENTS OF VDI &
HOW IT WORKS?

Client Device: The endpoint device used
by the user to access the virtual desktop.
It could be a PC, tablet, or thin client.

Remote Display Protocol: Protocols like
RDP (Remote Desktop Protocol), PCoIP,
or HDX enable the virtual desktop
experience by transmitting the desktop
interface to the client device.
