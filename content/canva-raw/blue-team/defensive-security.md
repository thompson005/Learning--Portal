KEY AREAS OF DEFENSIVE SECURITY

Key Areas of Defensive Security

Network Security Protecting an organization's network using firewalls, IDS/IPS, and VPNs.

Endpoint Security Securing computers, servers, and mobile devices with EDR (Endpoint Detection & Response).

Application Security Identifying and fixing security flaws in software

(e.g., patching vulnerabilities).

Threat Intelligence Gathering information about potential threats and attackers to stay ahead.
